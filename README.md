# Casecobra

Cascobra is a web application that allows users to customize their iPhone cases with personal images. The platform enables a seamless flow from uploading an image to designing and purchasing a custom case.

## Features

* **User Authentication:** Sign up and log in to your account using Kinde for secure authentication.
* **Image Upload:** Upload an image to personalize your iPhone case.
* **Design Customization:** Customize the design of your case with our intuitive design tools.
* **Review & Checkout:** Review your final design and proceed to checkout using Stripe for a secure payment experience.

## Live Demo

Check out the live application at [Casecobra](https://casecobra-six.vercel.app/).

## Technologies Used

* **TypeScript** - For type-safe JavaScript development.
* **Next.js** - For server-side rendering and building the React application.
* **Kinde** - For user authentication.
* **Shadcn UI** - For UI components.
* **TailwindCSS** - For styling and responsive design.
* **Prisma** - For database management.
* **Neon** - For database hosting.
* **Stripe** - For handling payments.
* **Uploadthing** - For image uploading and management.

## Installation

To get started with Casecobra, follow these steps:

1. **Clone the Repository:**

```bash
git clone https://github.com/michaelorina/casecobra.git
```
2. **Navigate to the Project Directory:**
   ```bash
   cd casecobra
   ```
3. **Install Dependencies:**
   ```bash
   npm install
   ```
4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
The app will be available at [http://localhost:3000](http://localhost:3000).
